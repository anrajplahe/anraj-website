# Anraj — Personal Website

## Overview

A full-stack personal website designed to showcase my interests, experiences and projects across software development, technology, Bhangra and music.

The aim is to create a space that reflects who I am beyond my professional background, while developing my practical skills in modern web development, backend engineering and DevOps.

## Project Goals

- Create a modern, responsive and interactive personal website.
- Showcase my software projects and technical experience.
- Share my interests in technology products, Bhangra and music.
- Develop a backend API and database-driven content system.
- Implement a private dashboard for managing website content.
- Gain practical experience with testing, version control, CI/CD and deployment.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/anraj-website.git
```

Navigate into the project:

```bash
cd anraj-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
